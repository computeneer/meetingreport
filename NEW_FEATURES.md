# Meetings

- [x] Each meeting can have multiple notes.
- [x] When adding too many notes in the note modal, the bottom buttons disappear. To prevent this, the modal height should not exceed 80% of the viewport height. If it does, scrolling should be added.

# Users

- [x] Users should be dynamically addable. Therefore, users should be read from the JSON file.
- [x] The "/users" route can be used for adding, deleting, and editing users.
